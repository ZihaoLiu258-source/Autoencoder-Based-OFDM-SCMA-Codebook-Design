# Tools

- `check_repository.py`: dependency-free structure, syntax, JSON, file-size, and path-portability audit.
- `validate_phase1_artifacts.py`: checkpoint hash/support and BER raw-count integrity audit.
- `plot_codebook_constellations.py`: regenerate codebook-geometry panels under `artifacts/main/figures/`.

Run tools from the repository root with `python -m tools.<module>`.
